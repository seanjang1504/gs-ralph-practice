ST HTML 버전 안내

HTML·CSS·JavaScript 정적 파일만 사용합니다. 서버 프로그램, npm 설치, 환경변수, 외부 데이터베이스가 필요하지 않습니다.

Vercel에 올리기

  1. index.html이 있는 st-static 폴더 전체를 준비합니다.
  2. Vercel Drop에 폴더를 넣고 배포합니다. index.html만 올리면 연결된 JavaScript가 없어 실행되지 않습니다.
  3. 설정을 직접 지정할 때는 Framework: Other, Build Command 없음, Output Directory는 프로젝트 루트로 지정합니다.
  4. 배포된 HTTPS 주소를 휴대폰에서 열고 카메라 사용을 허용합니다.

회사에서 허용한 정적 파일 배포 절차로 올리세요. Vercel 접속 자체나 외부 모델 다운로드가 차단된 경우에는 해당 접근 허용이 필요합니다. 파일 이름 변경이나 차단 우회를 사용하지 않습니다. 파일을 더블클릭하는 file:// 방식은 모듈·카메라 제약 때문에 지원하지 않습니다.

실제 AI 분석

공개 CLIP 모델을 브라우저의 WebAssembly로 실행합니다. 사진을 AI 서버로 보내지 않습니다. 처음 접속할 때 jsDelivr와 Hugging Face에서 라이브러리·모델을 약 180MB 다운로드합니다. 다운로드가 보안 정책으로 차단되면 AI 오류와 재시도를 안내하며 모의 판정으로 바꾸지 않습니다.

모델: Xenova/clip-vit-base-patch32, q8. 고정 revision: d15189d7028b43f1d3e65039190477f6af591c2a. API 키는 사용하지 않습니다. 최신 Chrome·Edge를 권장하며 기기 메모리와 처리 성능에 따라 오래 걸리거나 실행되지 않을 수 있습니다. 모든 ST 기기 지원이나 30초 처리를 보장하지 않습니다.

바나나·복숭아·수박의 외관 판정을 보조합니다. 숙도와 곰팡이·파손을 구분하며 판단이 어려우면 추가 확인을 안내합니다. 신뢰도 %는 설명 간 상대 일치도입니다. 내부 상태·냄새·식품 안전성·실제 정확도 확률을 측정하지 않습니다.

4대 신선 검수 참고

축산·채소·과일·수산의 선도 기준에서 15개 대표 품목군의 확인 항목, 예외와 출처를 조회하고 기준 데이터를 내려받을 수 있습니다. 공개 참고 자료를 보강한 것이며, 모델을 추가 학습하거나 모든 품목의 AI 분석을 지원하는 것은 아닙니다.

사진·접수 내역 저장

원본 사진과 연결 정보는 현재 기기·브라우저의 IndexedDB에만 저장됩니다. 새로고침 후에도 남지만 브라우저 데이터 삭제, 저장 공간 회수, 비공개 모드 종료로 사라질 수 있습니다. 다른 기기·브라우저·배포 주소와 공유되지 않으며 기존 PC 서버 기록도 자동 이관되지 않습니다. 저장 실패 시 완료로 표시하지 않습니다.

입고 목록과 업체 접수·승인·반려·MD 검토·매입차감은 데모 처리입니다. 해피콜 완료는 이 브라우저의 접수 기록 저장과 데모 응답 확인을 뜻합니다. 실제 업체로 전송하거나 매입차감을 실행하지 않습니다. D일 제한과 업체 승인 조건은 유지됩니다.

시연 순서

  1. AI 다운로드가 끝나면 ‘검수하기’에서 바코드를 인식하거나 ‘스캔하기’로 예시 상품을 선택합니다.
  2. 실입고 수량을 저장하고 ‘AI 선도 진단하기’를 누릅니다.
  3. 사진 촬영을 누르면 3·2·1 후 촬영하고 실제 AI로 분석합니다. ‘사진으로 시연하기’의 공개 사진도 사용할 수 있습니다.
  4. 부적합·추가 확인 결과에서 접수를 선택하고 불량 수량을 입력합니다. 실입고 10개 중 2개만 요청해도 실입고는 10개로 유지됩니다.
  5. 완료 창에서 홈 또는 계속 스캔하기를 선택하고 접수 내역을 확인합니다.
